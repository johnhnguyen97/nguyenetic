Supabase から Rust + Axum に移行している過程、その設計判断、つまずいた点を
共有します。

**二つ目** — エージェンシー業務の事例研究。Next.js と AI を使ってクライアントの
業務課題を解決した実例、レガシーシステムの近代化、サイト運用の現実。

**三つ目** — 西洋人エンジニアから見た日本語 UI の設計上の考慮点。日本での就職活動
を通じて得た学びを書きます。
